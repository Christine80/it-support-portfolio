#Windows Troubleshooting Project
Scenario
A user reports that their windows computer has become slow and is taking a long time to start

#Problem
The computer is experiencing slow performance during startup and normal use.

#Troubleshooting steps

1. Restart the computer to check whether the issue was temporary.
2. Checked the Task Manager to identify applications using high CPU, memory or disk resources.
3. Reviewed the startup apps section and identified unnecessary programs launching at startup.
4. Disabled unnecessary startup applications applications.
5. Checked available disk space.
6. Removed temporary files t free up storage space.
7. Restarted the computer and checked its performance.

#Results
The computer's startup and overall performance improved after unnecessary startup applications were disabled and temporary files were removed.
